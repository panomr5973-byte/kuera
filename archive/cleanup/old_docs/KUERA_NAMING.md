## ✨ Filosofi Nama

### **KUERA** / **ERAKU**

```
KUERA = Kumpulan/U... Era Rakyat
         ↓
      ERAKU = Era Ku (My Era)
         ↓
   Titik Balik = Turning Point
```

**Makna Mendalam:**
- **KU**: Kumpulan / Kita (collective)
- **ERA**: Era / Zaman (new era)
- **KU**: Ku / Aku (personal, mine)
- **ERAKU**: Era saya, era kita bersama
