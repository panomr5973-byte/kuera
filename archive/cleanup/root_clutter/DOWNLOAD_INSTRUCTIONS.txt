VERIFIKASI SETELAH DOWNLOAD
================================================================================

Setelah download selesai, verifikasi dengan:

1. Cek file yang ada:
   dir models\llm\*.gguf

2. Cek ukuran total:
   python check_download_progress.py

3. Update registry:
   python -c "
   import json
   from pathlib import Path
   registry = json.load(open('models/llm/llm_registry.json'))
   for f in Path('models/llm').glob('*.gguf'):
       size = f.stat().st_size / (1024**3)
       print(f'{f.name}: {size:.2f} GB')
   "

================================================================================
TROUBLESHOOTING
================================================================================

Jika download terputus:
  - HuggingFace otomatis resume download
  - Jalankan ulang perintah yang sama
  - Download akan melanjutkan dari posisi terakhir

Jika koneksi lambat:
  - Gunakan koneksi WiFi/Ethernet (bukan mobile)
  - Download di malam hari (traffic lebih rendah)
  - Gunakan VPN jika HuggingFace lambat

Jika HuggingFace tidak bisa diakses:
  - Gunakan VPN
  - Atau gunakan mirror/alternative source

================================================================================
