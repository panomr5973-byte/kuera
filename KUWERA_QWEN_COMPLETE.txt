METODE 1: OLLAMA (Recommended untuk Bahasa Indonesia)
-----------------------------------------------------------------------
Keuntungan:
  - Native support untuk GGUF
  - REST API built-in
  - Mudah digunakan
  - Support format chat Qwen

Setup:
  1. Install Ollama dari https://ollama.com
  2. Buka terminal/command prompt
  3. Jalankan: setup_ollama_qwen.bat
  4. Atau manual:
     ollama create kuera-qwen -f Modelfile
     ollama run kuera-qwen

Penggunaan:
  ollama run kuera-qwen
  > Halo, siapa kamu?
  > Bagaimana kondisi ekonomi Indonesia?

API:
  curl http://localhost:11434/api/generate -d "{"model": "kuera-qwen", "prompt": "Halo"}"
